# Smart Study Assistant 📚

Smart Study Assistant is a Python-based study management application designed to help students organize their learning, manage study tasks, track study time, and monitor their progress.

##  Features

- Add and manage subjects
- Create study tasks
- Set task priorities (Low, Medium, High)
- Mark tasks as completed
- Delete tasks
- Record study sessions
- Track total study time
- Daily study goals
- Progress dashboard
- Weak-subject analysis
- Search tasks
- SQLite database for permanent data storage

##  Technologies Used

- Python
- SQLite
- Object-Oriented Programming concepts
- SQL
- Database Management
- CRUD Operations
